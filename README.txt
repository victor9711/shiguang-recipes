我的 AI 菜譜 — 免費 PWA 原型

1. 把整個 recipe-app 資料夾部署到 HTTPS 靜態網站（例如 GitHub Pages），不能只用手機直接打開 file:// 來安裝 PWA。
2. 前往 https://aistudio.google.com/apikey 取得自己的 Gemini API Key。請查看免費額度與 Google 的資料使用條款。
3. 開啟網站，點選「設定」，貼上密鑰並儲存。
4. 選擇你有權使用的影片，按「用 Gemini 分析影片」。
5. 菜譜和影片會儲存在此網站於本機的 IndexedDB；並非手機相簿。定期匯出 JSON 並另行下載影片。
6. 可從手機瀏覽器選單選擇「加入主畫面」。

限制：
- 目前無法只貼小紅書連結就自動抓取影片；連結只用於原始出處保存。
- Google Gemini Files API 的瀏覽器直連可能受 CORS、配額或政策限制；需要時應改為安全的後端代理。
- 目前密鑰儲存在 localStorage，不適合多人共用或公開部署給其他人使用。
- 本機儲存空間由手機及瀏覽器決定，清除網站資料會失去菜譜與影片。
- 備份 JSON 只包含菜譜文字，不包含影片。
- 免費配額可能隨 Google 政策變動，無法保證永久免費或每天固定處理 10 條影片。
